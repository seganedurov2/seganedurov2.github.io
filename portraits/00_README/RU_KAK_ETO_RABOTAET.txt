КАК РАБОТАЕТ СИСТЕМА ИЗОБРАЖЕНИЙ ПЕРСОНАЖЕЙ
===========================================

Каждый персонаж в игре использует изображение из этого дерева папок. Больше
ничто не определяет его внешность: игра не распознаёт содержимое графического
файла. Поэтому изображение связывается с персонажем исключительно по месту его
расположения.

Если ты хочешь только добавить изображения, прочитай
RU_DOBAVLENIE_IZOBRAZHENIY.txt. Этот файл объясняет, как игра их использует.

1. ГДЕ НАХОДИТСЯ ЭТА ПАПКА
--------------------------

В готовой версии игры эта папка находится рядом с файлом .exe, как и папка
"saves". Это сделано намеренно: сюда можно добавлять собственные изображения,
не изменяя файлы установленной игры.

Содержимое этой папки не упаковывается в игру, поэтому ты всегда можешь свободно
его редактировать.


2. СТРУКТУРА ПАПОК
------------------

    portraits/
        01_north_america_central_caribbean/
            women/
            men/
            trans/
        02_south_america/
        ...
        14_australia_oceania/
        15_roma/
        ...
        21_andean/
        other/

Первые четырнадцать папок соответствуют регионам мира, из которых может
происходить персонаж. Следующие семь относятся к народам без собственного
государства, расселённым по разным регионам, поэтому один только регион мало
говорит об их внешности. Последняя папка описана в разделе 6.

Число в начале имени папки задаёт только порядок. Важна часть имени после
числа: она должна соответствовать региону или происхождению, известному игре.
Любая другая папка полностью игнорируется: она не появляется в списке и никогда
не используется.

Каждая из этих папок содержит одинаковые три подпапки: women, men и trans.


3. КАК ПЕРСОНАЖ ПОЛУЧАЕТ ИЗОБРАЖЕНИЕ
------------------------------------

При создании персонажа игра по порядку проверяет следующие места и
останавливается на первом, где есть подходящее изображение:

    1. Папка, соответствующая его происхождению, если такая существует.
       Для этого предназначены папки народов без собственного государства.
       Цыганка, родившаяся в Германии, получает изображение из 15_roma,
       а не из европейского региона.

    2. Папка региона, из которого происходит персонаж.
       Это определяет страна происхождения, а не рынок, на котором он появился.
       Нигерийка, купленная в Европе, по-прежнему получает изображение из
       07_west_africa.

    3. Любая известная игре папка региона или происхождения при совпадении пола.
       Это запасной вариант для региона, в котором пока нет подходящих
       изображений.

    4. Ни одно изображение — персонаж отображается как серый прямоугольник.

На каждом этапе транс-персонаж сначала проверяет подпапку trans/. Если она
пуста, он проверяет папку своего зарегистрированного пола и только затем
переходит к следующему этапу.


4. ПОЧЕМУ ОДНО И ТО ЖЕ ЛИЦО НЕ ПОЯВЛЯЕТСЯ ПОСТОЯННО
---------------------------------------------------

Игра выбирает изображения не полностью случайным образом. Она считает, сколько
персонажей в текущем составе уже используют каждое изображение в папке,
сортирует их по этому числу и отдаёт предпочтение наименее используемым. В
общей сложности 40 % наименее используемых изображений получают 65 %
вероятности выбора, а остальные делят между собой оставшуюся вероятность.

Из этого следуют две вещи:

  - Если изображений больше, чем персонажей, повторы встречаются редко.
  - Если изображений меньше, чем персонажей, повторы неизбежны, но они
    распределяются равномерно. Одно лицо не появляется двадцать раз, пока
    другое не используется ни разу.

Счётчик использования не хранится отдельно. Игра вычисляет его по персонажам,
которыми ты владеешь в данный момент, поэтому продажа или потеря персонажа
автоматически снижает использование его изображения. Новые изображения в часто
используемой папке получают явное преимущество, но не назначаются всем новым
персонажам подряд.


5. КАРТОЧКА, КАДРИРОВАНИЕ И ПОЛНЫЙ ПРОСМОТР
-------------------------------------------

Рамка изображения на карточке персонажа высокая и узкая, а при увеличении окна
она становится выше. Изображение масштабируется так, чтобы заполнить рамку;
выступающие части обрезаются.

Поэтому карточка обычно показывает обрезанный фрагмент, а не всё изображение.
Есть два способа настроить отображение:

  - Кнопка настройки кадра позволяет отдельно для каждого персонажа выбрать,
    какую часть изображения показывает карточка.
  - Щелчок по изображению открывает полный просмотр без обрезки в исходном
    разрешении. Если изображение не помещается на экране, оно уменьшается.

Игра не увеличивает исходное изображение перед показом. Если рамка больше,
интерфейсу приходится растягивать изображение, из-за чего оно выглядит
размытым.


6. ПАПКА "other"
----------------

Эта папка предназначена для изображений, которые должны назначаться только
вручную. Она не участвует в автоматическом выборе, поэтому сгенерированный
персонаж никогда не получит ни одно из её изображений. Окно выбора отображает
её так же, как остальные папки, и позволяет назначить изображение вручную.

Используй её для изображения, подготовленного для одного конкретного персонажа,
если не хочешь, чтобы оно было назначено кому-либо ещё.


7. ВЫБОР ИЗОБРАЖЕНИЯ ВРУЧНУЮ
----------------------------

При наведении указателя на изображение в карточке персонажа появляется
небольшая панель с двумя кнопками. Одна настраивает текущий кадр, другая
открывает окно выбора изображения.

Окно выбора открывается в папке персонажа, а его пол уже выбран. Папки без
изображений для этого пола отображаются приглушёнными. Щелчок по миниатюре
выделяет её, лупа в углу открывает полный просмотр, а кнопка «Применить»
назначает изображение. До подтверждения ничего не меняется.

При смене изображения удаляется кадр, настроенный для предыдущего, поскольку
настройка кадра относится к изображению, для которого она была создана.


8. ЕСЛИ ИЗОБРАЖЕНИЕ ПРОПАЛО
---------------------------

Изображение персонажа хранится как путь к файлу. Если удалить файл,
переименовать его или переместить в другую папку, сохранённый путь больше не
будет на него указывать.

При загрузке сохранения игра обнаруживает такие случаи и по обычным правилам
выбирает замену для каждого затронутого персонажа. Вместо серого прямоугольника
появляется новое изображение, а обычное взвешивание по использованию продолжает
ограничивать повторы в составе. Настройка кадра пропавшего изображения также
удаляется, поскольку она была создана для изображения, которого больше нет.

Персонажи, которым изображение никогда не назначалось, остаются без изменений.
Они ничего не потеряли, а назначение им лица при загрузке было бы изменением,
которого никто не просил.

Если отсутствует вся папка portraits, игра ничего не заменяет. Сохранённые пути
остаются без изменений, поэтому после возврата папки исходные изображения
восстанавливаются без необратимого изменения сохранения.


9. КОГДА ИГРА ОБНАРУЖИВАЕТ ИЗМЕНЕНИЯ
------------------------------------

Игра считывает дерево папок только один раз при запуске. Изображения,
добавленные во время работы игры, появятся только после перезапуска.
