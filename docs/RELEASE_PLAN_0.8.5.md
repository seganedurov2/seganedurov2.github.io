# Release Plan 0.8.5 — "i18n и тексты"

## Цель
Закрытие хардкода, консистентность ru/en, безопасные fallback.

## Фокус
- Существующая i18n-инфраструктура проекта; не ломать ключи.
- UI-тексты и пользовательские сообщения engines, где они формируются.

## Задачи
- [ ] Инвентаризация новых/проблемных строк 0.6–0.8, вынос в словари ru/en.
- [ ] Плейсхолдеры/форматирование денег/дат — единый подход.
- [ ] Fallback при отсутствии ключа, проверка на пустые строки.
- [ ] Тесты/скрипт-проверка: отсутствие критичных missing keys в smoke-наборе (если есть инструмент).
- [ ] `changelog.txt` и версия `0.8.5`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Ключевые экраны 0.6–0.8 корректны на ru/en (smoke).
- [ ] Старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
