# Release Plan 0.8.3 — "Финансы и займы"

## Цель
Кредиты, банкротство, отчётность и прогноз денежных потоков.

## Фокус
- Займы/банкротство, `FinanceHistoryPanel`/отчёты, связь с `weeklyEconomy`.
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).

## Задачи
- [ ] Кредиты: график выплат, проценты/штрафы, досрочное погашение, лимиты.
- [ ] Банкротство: триггеры, процедуры, последствия, понятный UI.
- [ ] Отчётность: история по неделям, P&L/долги, прогноз кассового разрыва.
- [ ] Unit-тесты: платежи, дефолт/банкротство, отчётные суммы.
- [ ] Миграция финансовых полей — дефолты.
- [ ] `changelog.txt` и версия `0.8.3`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
