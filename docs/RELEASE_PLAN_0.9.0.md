# Release Plan 0.9.0 — "Pre-1.0 RC"

## Цель
Фича-фриз, полировка, документация, совместимость и релизная готовность.

## Фокус
- Только критичные фиксы, совместимость, UX-полировка, документация.
- Любые изменения данных — строго через миграции.

## Задачи
- [ ] Фича-фриз: новые механики только по критичной необходимости; всё остальное — backlog после 1.0.
- [ ] Совместимость сейвов: фикстуры старых версий, round-trip, понятные ошибки импорта.
- [ ] Качество: закрыть/задокументировать lint baseline, прогнать полный test/build/tsc, smoke ключевых сценариев.
- [ ] Баланс/UX: финальная проверка читаемости, переполнений, текста ошибок.
- [ ] Документация: обновить `changelog.txt`, релизные заметки, известные ограничения.
- [ ] Версионирование: `package.json`, lockfile, Android `versionCode`/`versionName` по политике проекта.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные (baseline явно зафиксирован, если есть).
- [ ] Старые сохранения и мета-прогресс загружаются.
- [ ] Критические пользовательские петли проходят smoke.

## Примечания
- Emporium-app (React/Vite/TS). Текущая ветка работы: `axiomatic-decision`.
- Не менять формат сохранений без миграции.
