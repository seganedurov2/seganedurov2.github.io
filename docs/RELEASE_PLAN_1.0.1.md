# Release Plan 1.0.1 — "Unity port + Race"

## Цель
Промежуточный релиз между текущим прототипом и полноценной 1.0: завершение переноса ядра на Unity (C#), фича «Гонка» (R1–R6), баланс и полировка обоих клиентов.

## Статус на начало спринта
- **Веб (app/)**: полное ядро (~30 движков), сохранения, мета-прогресс, валюта БИН.
- **Unity (unity/)**: только меню (UI Toolkit), тик дня, заведения, найм, JSON-сейвы. Unity Editor не установлен в CI — компилировать C# можно только локально.

## Фокус
- Любое изменение сейва — через `migrateCampaignState`, старые слоты должны открываться без потерь.
- Новые поля только с дефолтами.
- Замена BTC → БИН: больше нигде не встречается `₿`, `btc`, `BTC`, `bitcoin`.

## Этапы

### М1 — Ядро Unity (C#)
- [ ] M1.1 `TreasuryEngine` — начисление доходов/расходов заведений, банкротство (`TickDay` корректно меняет `funds`, ставит `isBankrupt`).
- [ ] M1.2 `BankruptcyEngine` — процедура банкротства, ресивершип (сохранение/загрузка банкротного кейса).
- [ ] M1.3 `HospitalEngine` — палаты, оборудование, пациенты (пациенты занимают места, 비용 больницы в тике).
- [ ] M1.4 `CaravanEngine` — караваны, рейды, страховка (караваны отправляются, возвращаются с убытком/прибылью).
- [ ] M1.5 `CaptureOpsEngine` — операции похищения (операции создаются, завершаются, дают рабов).
- [ ] M1.6 `SaveSystem` — round-trip всех полей, битые сейвы (тест сохранения/загрузки без потери данных).

### М2 — Гонка (веб + Unity)
- [ ] R1 Модель `RaceHorse`, `RaceEvent`, `RaceState`, нормализация сейва (round-trip + битый сейв тесты).
- [ ] R2 Движок заезда: шанс победы (форма/усталость/погода), ставки, допинг-скандал (`raceEngine.test.ts` детерминированный, seeded rng).
- [ ] R3 UI: календарь заездов, карточки лошадей, ставки (`RaceTab` в навигации, Escape-стек учтён).
- [ ] R4 Недельный цикл: содержание стойла, лечение, долги владельцам (отчёт недели содержит `revenue.race` / `expenses.race`).
- [ ] R5 Мета: достижения «Первый круг», «Дерби», lifetime-статистика (правило в `metaProgressEngine` + тест).
- [ ] R6 Баланс и тексты, changelog, версия (прогон экономики на 20 недель без NaN).

### М3 — Полировка и баланс
- [ ] P1 Прогон экономики веба на 20 недель (без NaN, без отрицательной казны без банкротства) — скрипт симуляции.
- [ ] P2 Баланс заведений Unity (доход/расход/уровень) — типовые кампании не уходят в банкротство до 5-й недели.
- [ ] P3 Русификация всех новых строк Unity (HUD, кнопки, панели) — нет хардкода на английском в UI.
- [ ] P4 changelog.txt + версия 1.0.1 — файл актуален.

## Регрессии, за которыми следить
- `migrateCampaignState` — новые поля только с дефолтами, старые сейвы грузятся.
- `escapeStack` — модалки гонки занимают один слой Escape.
- `saveState.test.ts` снимки — обновлять при новых полях.
- Фин. отчёт: `revenue.race` / `expenses.race` попадают в `normalizeWeeklyReport`.
- Замена BTC → БИН: больше нигде не встречается `₿`, `btc`, `BTC`, `bitcoin`.

## Вне рамок 1.0.1
- Онлайн-заезды между игроками (хаб).
- Настоящая 3D-физика заездов (только UI-заезды).
- Продажа лошадей на аукционе (после лота-животных).
- Android-портирование Capacitor.

## Критерии приёмки
- [ ] `npx vitest run` — зелёные.

- [ ] `npx vite build` — бандл собран.
- [ ] `npm run lint` — 0 ошибок.
- [ ] Unity C# компилируется локально (`dotnet test`).
