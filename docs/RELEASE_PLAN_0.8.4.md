# Release Plan 0.8.4 — "Безопасность и юристы"

## Цель
Риски, проверки, правовые/охранные меры и смягчение событий.

## Фокус
- Безопасность, рейды/инциденты, события/банкротство — интеграция через существующие движки.
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).

## Задачи
- [ ] Уровни защиты: стоимость, покрытие рисков, влияние на рейды/инциденты/проверки.
- [ ] Юридические действия: снижение штрафов/рисков, кулдауны, ограничения по средствам/репутации.
- [ ] UI: сводка рисков, активные меры, «что покрыто / не покрыто».
- [ ] Unit-тесты: модификаторы риска, применение мер.
- [ ] Миграция новых полей — дефолты.
- [ ] `changelog.txt` и версия `0.8.4`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
