# Release Plan 0.7.3 — "Аукционный дом"

## Цель
Лоты, инспекция, торги, репутация и защита от переполнения/ошибок UI.

## Фокус
- `auctionHouseEngine.ts`, `AuctionHouseTab.tsx`, интеграция согласий/продаж.
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).
- Тесты/линт/сборка должны проходить.

## Задачи
- [x] Торги/NPC: прозрачные правила ставки/победителя, влияние репутации/уровня, защита от NaN.
- [ ] Инспекция: стоимость/лимиты/исходы, связь с подделками и свалкой, журнал.
- [ ] Репутация аукциона: эффекты на спрос и доступность покупателей.
- [x] UI-аудит: длинные имена/категории/источники — `truncate`/переносы/tooltip, адаптив карточек, a11y кнопок.
- [x] Unit-тесты: valuation/inspection/sale, consent flow, bulk junkyard.
- [ ] Миграция полей аукциона/инспекций — дефолты.
- [x] `changelog.txt` и версия `0.7.3`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Нет переполнения текста в карточках лотов (smoke в узком viewport).
- [ ] Старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
