# Release Plan 0.8.6 — "Тема и UI-кит"

## Цель
CSS-переменные, контраст, состояния компонентов, консистентность тёмной/светлой темы.

## Фокус
- `index.css`/токены темы, общие UI-паттерны; глобальные стили через theme variables.
- Без изменения игровых формул.

## Задачи
- [ ] Аудит контраста/состояний (hover/focus/disabled/error) ключевых контролов.
- [ ] Унификация кнопок/бейджей/таблиц/модалок; `focus-visible` для a11y.
- [ ] Светлая/тёмная тема: проверка читаемости графиков/бейджей/overflow-карточек.
- [ ] Визуальный smoke (узкий viewport, длинные строки).
- [ ] `changelog.txt` и версия `0.8.6`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Нет критичных регрессий читаемости; старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
