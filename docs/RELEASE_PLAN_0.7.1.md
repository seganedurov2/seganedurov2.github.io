# Release Plan 0.7.1 — "Караваны и риски"

## Цель
Рейды, урон, страхование, прозрачные логи исходов.

## Фокус
- `caravanRaidsEngine.ts` и недельный цикл караванов — точечные изменения.
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).
- Тесты/линт/сборка должны проходить.

## Задачи
- [x] Модель рейда: шанс/урон/потери по маршруту и охране, детерминированные тесты (seed/контролируемый RNG).
- [x] Страхование/смягчение: стоимость, покрытие, условия; отображение «чистый итог» после рейда.
- [x] Очередь/разрешение рейдов: лимиты, UX нескольких событий за неделю, журнал в логах кампании.
- [x] UI караванов: риск маршрута, состав охраны, история инцидентов.
- [x] Unit-тесты: spawn/resolution, страховка, граничные вероятности.
- [x] Миграция новых полей каравана/страховки — дефолты.
- [ ] `changelog.txt` и версия `0.7.1`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
