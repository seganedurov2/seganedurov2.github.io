# Release Plan 0.7.9 — "Баланс и UX"

## Цель
Полировка баланса, производительность списков, доступность и качество UI.

## Фокус
- Точечные балансные правки в engines + объяснимость в UI.
- React-обвязка: мемоизация/виртуализация тяжёлых списков; `App.tsx` не раздувать.

## Задачи
- [ ] Баланс: ревизия «снежного кома»/убыточных тупиков, мягкие ограничители без ломки сейвов.
- [ ] UX: skeletons/empty states, единые паттерны `truncate`/tooltip для длинных строк, консистентные `formatMoney`.
- [ ] A11y: фокус/label/контраст для ключевых действий, клавиатурная навигация в модалках/таблицах.
- [ ] Производительность: профилирование больших ростеров/рынка/аукциона, уменьшение лишних ререндеров.
- [ ] Тесты: регрессии баланса (фиксированные сценарии), unit для затронутых утилит.
- [ ] `changelog.txt` и версия `0.7.9`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Нет заметных UI-регрессий переполнения текста в ключевых карточках.
- [ ] Старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
