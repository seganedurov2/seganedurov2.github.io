# Release Plan 1.0.2 — "Unity ядро + баланс"

## Цель

Завершить перенос ядра на Unity (C#), перенести фичу «Гонку» на Unity (UI Toolkit), провести баланс и полировку обоих клиентов, зафиксировать версию 1.0.2.

## Статус на начало спринта (итог 1.0.1)

- Веб (app/): полное ядро (~30 движков), сохранения, мета-прогресс, валюта БИН, фича «Гонка» (raceEngine, RaceTab, мета, weekly report с revenue.race/expenses.race). vitest/tsc/lint/build зелёные.
- Unity (unity/): только меню (UI Toolkit), тик дня, заведения, найм, JSON-сейвы. Unity Editor не установлен в CI — компилировать C# можно только локально (`dotnet test`).
- 1.0.1 «вне рамки»: онлайн-заезды между игроками, настоящая 3D-физика заездов, продажа лошадей на аукционе, Android-портирование Capacitor — остаются вне 1.0.2.

## Этапы

### М1 — Ядро Unity (C#) — завершение переноса

M1.1 TreasuryEngine — начисление доходов/расходов заведений, банкротство (TickDay корректно меняет funds, ставит isBankrupt).
M1.2 BankruptcyEngine — процедура банкротства, ресивершип (сохранение/загрузка банкротного кейса).
M1.3 HospitalEngine — палаты, оборудование, пациенты (пациентыoccupy места, 비용 больницы в тике).
M1.4 CaravanEngine — караваны, рейды, страховка (караваны отправляются, возвращаются с убытком/прибылью).
M1.5 CaptureOpsEngine — операции похищения (операции создаются, завершаются, дают рабов).
M1.6 SaveSystem — round-trip всех полей, битые сейвы (тест сохранения/загрузки без потери данных).

Готово, когда: `npm run test:core` (`dotnet test core/Emporium.Core.Tests`) — зелёное; старые JSON-сейвы открываются без потерь; новые поля только с дефолтами.

### М2 — Гонка на Unity (C# + UI Toolkit)

R1 Unity — модель RaceHorse/RaceEvent/RaceState, нормализация JSON-сейва (round-trip + битый сейв тесты на C#).
R2 Unity — движок заезда: шанс победы (форма/усталость/погода), ставки, допинг-скандал (детерминированный SeededRandomSource, битовое совпадение с веб-фикстурой).
R3 Unity UI — календарь заездов, карточки лошадей, ставки (вкладка Ипподром в навигации UI Toolkit).
R4 Unity — недельный цикл: содержание стойла, лечение, долги владельцев (доходы/расходы гонки в недельном отчёте).
R5 Unity — мета: достижения «Первый круг», «Дерби», lifetime-статистика.
R6 Unity — баланс и тексты, русификация всех новых строк (нет хардкода на английском в UI), changelog, версия.

Готово, когда: гонка работает на Unity parallel с вебом (одинаковый seed → одинаковый победитель), все строки на русском, changelog актуален.

### М3 — Полировка и баланс

P1 Прогон экономики веба на 20 недель (без NaN, без отрицательной казны без банкротства) — скрипт симуляции.
P2 Баланс заведений Unity (доход/расход/уровень) — типовые кампании не уходят в банкротство до 5-й недели.
P3 Русификация всех новых строк Unity (HUD, кнопки, панели) — нет хардкода на английском в UI.
P4 changelog.txt + версия 1.0.2 — файл актуален.

## Регрессии, за которыми следить

- migrateCampaignState — новые поля только с дефолтами, старые сейвы грузятся.
- escapeStack — модалки гонки занимают один слой Escape.
- saveState.test.ts снимки — обновлять при новых полях.
- Фин. отчёт: revenue.race / expenses.race попадают в normalizeWeeklyReport.
- Замена BTC → БИН: больше нигде не встречается ₿, btc, BTC, bitcoin.

## Вне рамок 1.0.2

Онлайн-заезды между игроками (хаб). Настоящая 3D-физика заездов (только UI-заезды). Продажа лошадей на аукционе (после лота-животных). Android-портирование Capacitor.

## Критерии приёмки

- `npx vitest run` — зелёные.
- `npx tsc -b --noEmit` — exit 0.
- `npx vite build` — бандл собран.
- `npm run lint` — 0 ошибок.
- Unity C# компилируется локально (`npm run test:core` → `dotnet test core/Emporium.Core.Tests`) — exit 0.
