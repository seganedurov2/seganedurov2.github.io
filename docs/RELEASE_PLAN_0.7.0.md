# Release Plan 0.7.0 — "Мезонин: город и экономика"

## Цель
Глубина city economy: налоги, содержание, стройка, понятные отчёты.

## Фокус
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).
- `cityEconomyEngine.ts`, `cityEconomyState.ts`, city-plan модули — инкрементально.
- Тесты/линт/сборка должны проходить.

## Задачи
- [x] Налоги/сборы и содержание зданий: формулы в engine, расчёт за неделю, отображение в отчёте/журнале.
- [x] Стройка/апгрейды: стоимость, сроки (если есть), эффекты и окупаемость; блокировки при нехватке ресурсов.
- [x] Отчётность: `withCityEconomyReport`/UI-сводка — доходы/расходы/баланс по городу, сравнение с прошлой неделей (если данные есть).
- [x] Городские события/риски (лёгкая версия): влияние на доход/расход с объяснением причины.
- [x] Unit-тесты: налоги, upkeep, отчётные итоги, крайние значения.
- [x] Миграция: новые поля плана/экономики — дефолты, совместимость старых `cityPlan`/сейвов.
- [x] `changelog.txt` и версия `0.7.0`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Старые сохранения/планы города загружаются.
