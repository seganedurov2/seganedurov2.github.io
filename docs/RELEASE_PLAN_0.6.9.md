# Release Plan 0.6.9 — "Сохранения и миграции"

## Цель
Версионирование save, тесты round-trip, надёжные дефолты и UX загрузки.

## Фокус
- `saveState.ts`/`campaignPersistence.ts`/импорт-экспорт — основной контур; изменения только с миграцией.
- Не ломать Android/Capacitor и Telegram Mini App слоты.
- Тесты/линт/сборка должны проходить.

## Задачи
- [ ] Явная версия схемы сейва (если ещё не везде): запись при сохранении, чтение/миграция по версии.
- [ ] `migrateCampaignState`: покрыть все новые поля 0.6.x, нормализация NaN/undefined/старых enum/отсутствующих массивов.
- [ ] Round-trip тесты: старые фикстуры → migrate → save/load → ключевые поля сохранены; импорт/экспорт.
- [ ] UX: понятная ошибка повреждённого сейва, опция резервной копии перед перезаписью слота (где уместно).
- [ ] Error Boundaries/guard’ы вокруг чтения сохранений, чтобы краш не убивал приложение.
- [ ] `changelog.txt` и версия `0.6.9`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Загружаются сохранения предыдущих минорных версий проекта (smoke-набор фикстур).
- [ ] Повреждённые/частичные данные не приводят к белому экрану.

## Примечания
- Emporium-app (React/Vite/TS). Текущая ветка работы: `axiomatic-decision`.
- Любое изменение формата сохранений — только через `migrateCampaignState`.
