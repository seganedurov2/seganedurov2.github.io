# Release Plan 0.7.4 — "Больница и здоровье"

## Цель
Лечение, травмы, оснащение, влияние персонала на исходы.

## Фокус
- `hospitalEngine.ts`, `chiefDoctorEngine.ts`, связанные UI-табы.
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).

## Задачи
- [x] Травмы/лечение: стоимости, длительность, риск осложнений, влияние навыка врача/оснащения.
- [x] Оснащение/палаты: апгрейды, дефицит ресурсов, понятные блокировки.
- [x] Связь со здоровьем/усталостью/беременностью (использовать существующие движки, не дублировать формулы).
- [x] UI: очередь пациентов, прогноз исхода/стоимости, журнал решений главврача.
- [x] Unit-тесты: лечение/износ/дефицит, edge cases.
- [x] Миграция больничных полей — дефолты.
- [x] `changelog.txt` и версия `0.7.4`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
