# Release Plan 0.8.2 — "Котельная и инфраструктура"

## Цель
Топливо, температура, автоматизация и влияние на здания/персонал.

## Фокус
- Котельная/инфраструктурные модули + регрессии автоматизации.
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).

## Задачи
- [ ] Ресурсы (топливо) и температура: потребление, пороги, аварии/штрафы.
- [ ] Автоматизация: политики, безопасность переключений, журнал решений.
- [ ] UI: состояние, прогноз расхода, алерты.
- [ ] Unit/регрессионные тесты (в т.ч. существующие boiler-house кейсы).
- [ ] Миграция новых полей — дефолты.
- [ ] `changelog.txt` и версия `0.8.2`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
