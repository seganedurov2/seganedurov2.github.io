# Release Plan 0.6.8 — "События и выборы"

## Цель
Расширение событийной системы: условия, последствия, контролируемая случайность.

## Фокус
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).
- `eventsEngine.ts`/`expansionEventsEngine.ts` — расширять через данные и чистые функции.
- Тесты/линт/сборка должны проходить.

## Задачи
- [x] Условия срабатывания: неделя/акт, репутация, финансы, наличие зданий/персонала, кулдауны; детерминированные проверки в тестах.
- [x] Последствия выборов: деньги/репутация/состояние, отложенные эффекты (если добавляются — хранить в сериализуемом виде, дефолты в миграции).
- [x] Анти-повтор: веса/кулдаун недавних событий, защита от пустого пула.
- [x] UI события: понятный текст последствий/рисков, недоступные выборы с причиной (если применимо).
- [x] Unit-тесты: выбор события по условиям, применение choice, кулдаун, отсутствие побочных мутаций входа.
- [x] Миграция: новые поля истории событий/кулдаунов — безопасные дефолты.
- [x] `changelog.txt` и версия `0.6.8`.

## Критерии приёмки
- [x] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [x] Старые сохранения загружаются; события не падают на отсутствующих полях.

## Примечания
- Emporium-app (React/Vite/TS). Текущая ветка работы: `bdsm`.
- Не менять формат сохранений без миграции.
