# Release Plan 0.8.8 — "Производительность"

## Цель
Ленивая загрузка, мемоизация, контроль размеров чанков и отзывчивость UI.

## Фокус
- Vite/React: code-splitting табов, memo/callback hygiene, виртуализация больших списков.
- Не менять игровые правила.

## Задачи
- [ ] Lazy-load тяжёлых вкладок/панелей; прелоад по намерению (hover/idle) при необходимости.
- [ ] Профилирование: ростер, рынок, аукцион, мезонин; устранить лишние ререндеры.
- [ ] Виртуализация/пагинация длинных таблиц (если объёмы большие).
- [ ] Контроль `build` чанков: крупные зависимости (3D/визуализации) изолировать.
- [ ] Smoke-тесты производительности вручную (инструкция в PR/notes) + регрессия функционала.
- [ ] `changelog.txt` и версия `0.8.8`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Нет функциональных регрессий; старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
