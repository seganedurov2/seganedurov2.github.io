# Release Plan 0.7.8 — "Кампания и акты"

## Цель
Сценарий кампании, цели актов, интеграция с квестами/таб-гейтингом.

## Фокус
- `campaignScript.ts`, квестовые/гейтинговые данные, панель кампании.
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).

## Задачи
- [ ] Акты/майлстоуны: условия завершения, награды, разблокировки вкладок.
- [ ] Интеграция с квестами: единый источник истины по прогрессу, отсутствие рассинхрона UI.
- [ ] UX: «что делать дальше», прогресс актов, финал/победа/поражение (связь с ending modal).
- [ ] Unit-тесты: advance/act milestones, snapshot, условия разблокировки.
- [ ] Миграция состояния кампании/скрипта — дефолты.
- [ ] `changelog.txt` и версия `0.7.8`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Старые сохранения загружаются, прогресс акта не теряется.

## Примечания
- Не менять формат сохранений без миграции.
