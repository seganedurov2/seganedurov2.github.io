# Release Plan 0.8.0 — "Мир и регионы"

## Цель
Глобальные регионы, репутация, региональные события и модификаторы.

## Фокус
- `marketEconomyEngine.ts` региональные поля, `regionalStanding`, маршруты/события.
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).

## Задачи
- [ ] Региональные репутации/доступ: пороги, эффекты на цены/риски/доступность контрактов.
- [ ] Региональные модификаторы спроса и событий (данные + engine).
- [ ] UI: карта/список регионов, статус, “почему цена/риск такой”.
- [ ] Unit-тесты: standing, модификаторы, миграция словарей.
- [ ] Миграция: новые региональные поля — дефолты/нормализация ключей.
- [ ] `changelog.txt` и версия `0.8.0`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
