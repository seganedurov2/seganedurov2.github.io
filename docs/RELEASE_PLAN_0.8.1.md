# Release Plan 0.8.1 — "Склад и логистика"

## Цель
Мезонин склада, ресурсы, лимиты, связь с цепочками поставок.

## Фокус
- `warehouseEngine.ts`, UI склада, интеграция с закупками/контрактами/производством.
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).

## Задачи
- [ ] Ёмкость/уровни склада: хранение, апгрейды, upkeep, блокировки операций при переполнении.
- [ ] Ресурсы/категории: учёт, списания, порча/сроки (только если модель данных готова и мигрируема).
- [ ] UI: остатки, прогноз недели, предупреждения дефицита/переполнения.
- [ ] Unit-тесты: canStore/upgrade, списания, миграция.
- [ ] Миграция складских полей — дефолты.
- [ ] `changelog.txt` и версия `0.8.1`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные.
- [ ] Старые сохранения загружаются.

## Примечания
- Не менять формат сохранений без миграции.
