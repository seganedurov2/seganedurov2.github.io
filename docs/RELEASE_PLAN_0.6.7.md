# Release Plan 0.6.7 — "Персонал и здания"

## Цель
Найм/специализации, апгрейды зданий, прозрачные эффекты на экономику и риски.

## Фокус
- Стабильность и обратная совместимость сохранений (`migrateCampaignState`).
- `employeesEngine.ts`, `staffingCalculator.ts`, `buildingsEngine.ts` — точечные расширения.
- Тесты/линт/сборка должны проходить.

## Задачи
- [x] Специализации: матрица «роль/спец → эффект» (выручка, качество, риск, скорость), валидация совместимости с вакансией/полом где требуется существующей логикой.
- [x] Апгрейды зданий: стоимость, время/недели (если вводится — через миграцию/дефолт), upkeep, окупаемость/дельта в UI.
- [x] Эффекты зданий в недельном цикле: единый расчёт вклада (модификаторы выручки/расходов/рисков) без дублирования в React.
- [x] UI персонала/зданий: карточки с «что даёт сейчас», сравнение до/после апгрейда, предупреждение о нехватке средств/штата.
- [x] Unit-тесты: staffing/hiring quote, эффекты апгрейда, специализация edge cases, weekly effects без NaN.
- [x] Миграция: новые уровни/флаги апгрейдов и поля сотрудников — дефолты, совместимость со старыми слотами.
- [x] `changelog.txt` и версия `0.6.7`.

## Критерии приёмки
- [ ] `npm run lint`, `npm test`/`vitest run`, `npm run build`, `npx tsc -b --noEmit` — зелёные (или документированный baseline lint).
- [ ] Старые сохранения загружаются; новые поля нормализуются.
